# 🚀 TaskFlow

**TaskFlow** is a modern, responsive to-do list web app with a premium dark theme and glassmorphism design. It is built with plain HTML, CSS and JavaScript, with no frameworks or build tools.

## ✨ Features

- Add, edit, delete and complete tasks
- Priority levels: High, Medium and Low, shown as colored badges
- Filters: All, Active and Completed
- Live task counter and a "Clear completed" button
- Dashboard with total, active, completed and high-priority stats
- Animated progress bar
- Tasks saved in `localStorage`, so they persist after a refresh
- Friendly empty-state messages
- Responsive layout for mobile and desktop
- Smooth animations and hover effects
- Safe rendering that escapes user input

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, custom properties, backdrop-filter)
- Vanilla JavaScript (ES6)

## ⚙️ Setup

1. Clone the repository:
```bash
   git clone https://github.com/your-username/taskflow.git
```
2. Open the folder:
```bash
   cd taskflow
```
3. Open `index.html` in any modern browser. No installation is needed.

## 📖 How to Use

- Type a task, choose a priority and click **Add Task**.
- Tick the checkbox to complete a task.
- Click ✏️ to edit (press **Enter** to save, **Esc** to cancel).
- Click 🗑️ to delete.
- Use the filter buttons to switch views.
